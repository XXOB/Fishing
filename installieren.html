PetriKlar als Angel-App installieren

PetriKlar ist eine installierbare Web-App. Du kannst die Angel-App ohne App Store auf deinem Startbildschirm ablegen und anschließend wie eine eigenständige App öffnen.

Angel-App auf iPhone und iPad installieren

  1. Öffne www.petriklar.com in Safari.
  2. Tippe in Safari auf das Teilen-Symbol.
  3. Wähle Zum Home-Bildschirm.
  4. Bestätige mit Hinzufügen.

Angel-App auf Android installieren

  1. Öffne PetriKlar in Chrome.
  2. Öffne das Browsermenü mit den drei Punkten.
  3. Wähle App installieren oder Zum Startbildschirm hinzufügen.
  4. Bestätige die Installation.

Installation unter Windows oder macOS

Chrome und Edge zeigen bei einer installierbaren Web-App ein Installationssymbol in der Adresszeile oder den Menüpunkt PetriKlar installieren.

Hinweis zur Offline-Nutzung

Die App-Oberfläche wird für eine zuverlässige Installation zwischengespeichert. Persönliche Fangbuchdaten liegen aus Datenschutzgründen ausschließlich im Cloud-Konto und benötigen derzeit eine Internetverbindung.
